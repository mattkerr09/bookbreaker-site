How often did a player clear a number?

Choose the number before you count. Mark each played game that reached it, including a game equal to the number. Count those marks as k, and all the played games in your window as n. Read the result as k of n. Keep a season count beside a recent count so the window stays clear.

Make the question precise

“Clear” can be unclear. Does a game equal to your number count? Here it does. I use “24 or more points” rather than “over 24.” Write that rule down before looking at the scores. Changing the rule after seeing the answer makes a different question, even when the words sound close.

Next choose the subject, the stat and the window. A player’s points and a team’s points need separate rows. Use games played rather than calendar days. A date gap does not create an extra result. If there are not enough played games for your chosen window, write the count you actually have.

A team example from Detroit

This is a team example because the local data file has team scores, with no player logs. The rule here is Detroit Lions points at or above 24 in the 2025 regular season. Postseason games are left out. Games are sorted by date, then game ID. The last 10 played games are taken from that ordered list.

The recent count is 7 of 10. The season count is 12 of 17. Neither replaces the other. The recent view answers a shorter question. The season view includes earlier games too. Both use the same threshold and the same rule for an equal score. The range describes sampling uncertainty, under a model with a steady underlying rate.

Count the rows yourself

Here are the recent rows used in the first line. Read down the points column and mark each score that reaches the number. Count the yes marks. Then count every row, including the no marks. That second count is the denominator. Do not leave out a low score because it looks unusual.

To turn the count into a percentage, divide the yes count by the row count and multiply by 100. Round at the end. Keep the unrounded count beside it. A rounded percentage alone can hide the difference between a short run and a much longer record. It can also hide that a filter removed games from your sample.

Make a fair comparison

If you split home and away, start again with the filtered rows. Do not keep the full-season denominator after removing away games. If you change the threshold, count the marks again. Keep a note of the date, season and filter so someone else can repeat the same work. That is more useful than a number with no trail back to its games.

Questions

Does exactly the chosen number count?

Yes, for the rule on this page. “At or above” includes equality. If you want a strict greater-than rule, write that down and recount. Do not mix the two rules in one table.

What if the player missed a game?

Count games the subject played. Skip missed games in both the window and the later games. Player minutes and snaps are outside the first version.

Does this tell me what happens next?

No. It describes the games in the stated window. You can study later games separately, but this count alone cannot promise another result. A range helps show the doubt left by a short sample.
