Where can I read free NBA player game logs?

Use the league’s own player game-log page first. You can read the played games, choose a stat and count the rows yourself. For a last 10 view, take the newest 10 games the player actually played. Keep the dates and your chosen number beside the count so you can check the result again.

Start at the league’s page

The NBA player game-log table was tested in a browser on 20 November 2026. Its URL pattern is nba.com/stats/player/<id>/boxscores-traditional.

The NFL player game-log table was tested in a browser on 20 November 2026. Its URL pattern is nfl.com/players/<slug>/stats/logs/. Older seasons use the season choice on that page.

These are URL patterns. Replace the player ID or name placeholder with the one for the player you want. The source notes tested LeBron James for the NBA and Josh Allen for the NFL. A saved read tells you what was checked then; it cannot promise how a page will load on another day. The free route is to read the league’s page and do the count yourself.

I would start with the raw rows before paying for a more convenient view. It gives you something to compare with an app’s answer. Keep the player’s name, the season and the chosen stat on your note. A count loses its meaning quickly if you cannot tell which table it came from.

Read the last 10 played games by hand

Put the games in date order. Start at the newest played game and work backward until you have the window you want. Do not confuse a team’s schedule with the games the player played. Keep fewer rows if that is all you have, and say how many you counted. Never fill a missing played game with a zero just to finish the window.

A handwritten last-10 worksheet
StepWhat to keepCheck
Choose a questionPlayer, season, stat and numberWrite it before counting
Set the windowNewest 10 played gamesKeep the dates on the rows
Mark each rowAt or above the chosen numberAn equal value counts
Report the resultMarks of played rowsKeep the count beside any percentage

For each row, compare the selected stat with your number. Make a mark when the stat is equal to or above it. Count the marks, then count all the rows used. Write the answer as k of n. If you also want a percentage, divide k by n and multiply by 100. Keep k and n visible after rounding.

Read the column heading again before counting. Points, minutes and another stat are different questions. Keep the same stat throughout the window. If you change a season or a filter, start the row check again. A result copied from an earlier view may no longer match what is in front of you.

A check you can repeat

Save your written rule with the date you read the page. A second pass should start from the rows, rather than from your earlier total. Count the marks again without looking at the answer. If the totals disagree, compare the dates and the threshold rule first. Then compare each included row. That leaves a short path to finding the difference.

The worked example on this site uses Detroit team points from a local NFL schedules file. It cannot answer a player question. Use the league route above for the player you are researching, and keep the source with your own count.

Questions

Do I need to buy BookBreaker to count a log?

No. You can read a source table and count its rows by hand. BookBreaker is in development. The free method on this page stands on its own.

Should I count a game the player missed?

Count games the subject played. Skip missed games in both the window and the later games. Player minutes and snaps are outside the first version.

Can I copy the percentage without the rows?

You can write it down, but also keep its game count and window. Without those, you cannot tell what the percentage summarizes or repeat the work when you check it later.

Is a team score a player log?

No. Team scores explain the arithmetic here. To answer a player question, use that player’s own rows for the selected stat and season.
