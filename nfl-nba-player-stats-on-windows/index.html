Is there an NFL and NBA player stats tool for Windows?

Yes, through a web browser today. The NFL and NBA both publish player game logs that open in a browser on a Windows PC. For NFL numbers you can also load the free nflverse weekly file into a spreadsheet and count games yourself. BookBreaker is a planned Mac and Windows app, still in development, with no download yet.

Two league tables that open in a browser

The NBA player game-log table was tested in a browser on 20 November 2026. Its URL pattern is nba.com/stats/player/<id>/boxscores-traditional.

The NFL player game-log table was tested in a browser on 20 November 2026. Its URL pattern is nfl.com/players/<slug>/stats/logs/. Older seasons use the season choice on that page.

Chrome, Firefox and Microsoft’s own browser all run on Windows, so a PC can read both tables with nothing extra installed. Swap the placeholder in each pattern for the player you want. Each table lists a player’s games one row at a time, which is all a hand count needs. Write the date you read the page beside your note, because a league table can change after a stat correction.

Count NFL games in a spreadsheet

For the NFL there is a second free route. The nflverse project publishes weekly player statistics as CSV files on GitHub. Excel and LibreOffice Calc both open a CSV on Windows. One file holds every player and week of a season, so a few filters turn it into a game log you control.

Counting one player in the nflverse weekly CSV
StepWhat to doResult
Keep one playerFilter player_display_name to one name and season_type to REGRegular-season rows only
Put the weeks in orderSort by week, oldest firstThe newest games end the list
Choose one columnpassing_yards, rushing_yards or receiving_yardsOne stat per count
Count reaches=COUNTIF(range,">=75") over the newest 10 rowsThis gives k
Count rows=COUNT(range) over the same rowsThis gives n

A row in this file comes from recorded plays. If a player was active but recorded nothing in a game, that week may be missing. Compare your row count with the league’s game log before you trust n. The file is shared under CC BY 4.0, so credit nflverse when you pass a table along. The Sources section below shows the credit line this site uses.

Read down the last column. He reached 75 yards in 5 of those 10 games, with a Wilson 95% range of 24% to 76%. Across all 17 games he played that season, the count was 9 of 17, with a range of 31% to 74%. The short window and the season answer different questions, so keep both counts in view.

The NFL player stats pages repeat this layout for 273 players, with splits and a later-games check. They are ordinary web pages, so they work in any Windows browser. This site has no NBA player tables. For an NBA player, the league’s own game log and a hand count remain the route.

Questions

Does the NBA game log need an install on Windows?

No. It is a web page, read in a browser. Our notes record a browser test of the table and its URL pattern.

Can I get BookBreaker for Windows now?

Not yet. BookBreaker is in development. There is no download and no launch date.

Can I share a table made from the nflverse file?

The data is licensed CC BY 4.0, which allows sharing and adapting with credit. Read the licence itself for the full terms before you publish anything.

Why does this site show NFL players only?

Its player tables come from the public nflverse NFL files. No NBA file of that kind is part of this site’s build, so NBA counts here are by hand.
