Start with the game count behind each rate. Then look for a range, recent games beside the season, and filters for home or away and opponent. A single percentage leaves too much out. Choose the device and payment plan that fit how you read stats, after checking what is available today.

Read the denominator first

A player stats app should let you see which games make up a number. Start with the count. A rate without its games can hide a small sample, an old season or a filter you forgot was on. Keep the recent view beside the season so those questions are easy to ask before you make sense of the result.

A checklist for a player stats view
Look forWhat should be visibleQuestion to ask
Game countA count beside every rateHow many played games made this number?
RangeLow and high ends beside the rateHow much sampling doubt remains?
WindowLast 5, 10, 20 and the seasonAm I reading a recent run or the whole season?
ContextHome or away, and opponentWhich games did a filter leave out?

A useful range shows the doubt around an observed share under stated assumptions. It is not another score for the next game. A useful filter changes the denominator as well as the count of reaches. When you move from all games to home games, check that both parts of the answer moved with the rows.

Questions

Which window should I start with?

Start with the window in your question. If you want recent games, compare them with the season rather than silently switching between the two. A longer window can include older conditions.

Does a range tell me the next result?

No. It estimates uncertainty about a rate under a statistical model. It does not remove changes in conditions or make the next game certain. Read its assumptions as well as its endpoints.
